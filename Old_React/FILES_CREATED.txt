🎯 PROCHAINES ÉTAPES:

1. Installer dépendances:
   $ npm install

2. Lancer développement:
   $ npm start

3. Ajouter tes images (voir IMAGE_GUIDE.md):
   src/assets/images/hero/
   src/assets/images/destinations/
   src/assets/images/blog/
   src/assets/images/gallery/
   src/assets/images/services/

4. Personnaliser contenu:
   - Remplacer les emails/téléphones
   - Modifier les articles blog
   - Ajouter plus de FAQs
   - Enrichir descriptions

5. Déployer:
   $ npm run build
   Vercel / Netlify / GitHub Pages
